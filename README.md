### 📃 Interactive To Do List
![TypeScript](https://img.shields.io/badge/TypeScript-3178C6?style=for-the-badge&logo=typescript&logoColor=white)
![SCSS](https://img.shields.io/badge/SCSS-CC6699?style=for-the-badge&logo=sass&logoColor=white)

Interactive To Do List using vanilla-TS and Sass for styling. It's persisted using Local Storage. 

_💡 To run this project locally, make sure to install the Live Server extension in Visual Studio Code and launch the index.html file using it_

### 🚀 Installation: 

1. Clone this repository

```bash
git clone https://github.com/your-username/your-repo.git
```

2. Open the project folder in Visual Studio Code

3. Ensure the Live Server extension is installed

4. Right-click on index.html inside /public and select “Open with Live Server” to launch the app in your browser

⚠️ Make sure you have no conflicting ports running if Live Server doesn’t respond
